# Implementation Plan

- [x] 1. 永続化データ基盤の追加
- [x] 1.1 進行状態・履歴・目標・スコアをユーザー単位で保存できるようにする
  - 進行状態と履歴を分離し、時系列で参照可能にする
  - 目標の状態・理由・進捗ラベルを保持する
  - スコア指標と差分を保持する
  - _Requirements: 1.4, 1.5, 2.2, 2.4, 3.5, 4.1, 4.4_

- [x] 1.2 直近履歴の取得順序と件数制御を整備する
  - 最新順で取得し、UI 初期負荷を抑える
  - サマリに必要な集計値を取得できるようにする
  - _Requirements: 1.5, 3.5, 5.1, 5.4_

- [x] 2. ゲームプレイ状態サービスの実装
- [x] 2.1 ダッシュボード向けの集約データ取得を実装する
  - 進行状態・目標・直近履歴・スコア・サマリを一括で返す
  - ユーザー未選択時は明確なエラーを返す
  - _Requirements: 1.4, 3.5, 4.1, 5.1, 5.4_

- [x] 2.2 フェーズ更新と履歴追記を実装する
  - フェーズ進行の妥当性を検証し、履歴に記録する
  - _Requirements: 1.3, 1.5_

- [x] 2.3 目標の達成更新と無効化理由の反映を実装する
  - 達成済みの履歴を参照できるようにする
  - _Requirements: 2.2, 2.3, 2.4_

- [x] 2.4 アクション結果の記録と差分ハイライト保存を実装する
  - 成功・失敗・処理中を区別して記録する
  - _Requirements: 3.1, 3.3, 3.4, 3.5_

- [x] 2.5 評価指標の算出と不足理由の保持を実装する
  - 指標差分と総合スコアを保持する
  - _Requirements: 4.1, 4.2, 4.3, 4.4, 4.5_

- [x] 3. ログインゲートとユーザー情報の UI 追加
- [x] 3.1 ユーザー選択または作成のゲートを用意し、未選択時は入力導線のみ表示する
  - 処理中は操作不可であることを示す
  - _Requirements: 1.4, 3.2_

- [x] 3.2 選択済みユーザーの情報パネルを表示する
  - ユーザー名と現在の文脈を明示する
  - _Requirements: 1.4_

- [x] 3.3 ログイン後にダッシュボードと契約フローを開く導線を整える
  - 次のアクションへ進める導線を配置する
  - _Requirements: 5.5_

- [x] 4. ダッシュボードサマリ UI の追加
- [x] 4.1 主要リソースと最新状況のサマリを表示する
  - 状態変化時に最新情報へ更新する
  - _Requirements: 5.1, 5.4_

- [x] 4.2 サマリアイテムから詳細画面への誘導と空状態ガイドを整える
  - データがない場合のガイダンスを表示する
  - _Requirements: 5.2, 5.3, 5.5_

- [x] 5. 契約フローの進行可視化
- [x] 5.1 フェーズと残りステップの表示を追加する
  - 進行中は常に可視化する
  - _Requirements: 1.1, 1.2_

- [x] 5.2 フェーズ完了時の更新と再訪時の復元を反映する
  - 最新の進行状態を読み込み表示する
  - _Requirements: 1.3, 1.4_

- [x] 6. 目標・結果・履歴・スコアのパネル追加
- [x] 6.1 目標一覧と達成状況、期限切れ理由の表示を行う
  - 達成済みと未達成を一目で識別できる表現にする
  - _Requirements: 2.1, 2.3, 2.5_

- [x] 6.2 達成済み目標の履歴と直近アクション履歴を表示する
  - 進行履歴を参照できるようにする
  - _Requirements: 1.5, 2.4, 3.5_

- [x] 6.3 アクション結果の概要、処理中、失敗理由、差分ハイライトを表示する
  - 失敗時に次の行動のヒントを提示する
  - _Requirements: 3.1, 3.2, 3.3, 3.4_

- [x] 6.4 評価指標、差分、総合スコア、説明と不足理由を表示する
  - 指標の意味を確認できるようにする
  - _Requirements: 4.1, 4.2, 4.3, 4.4, 4.5_

- [x] 7. 契約確定時の統合更新
- [x] 7.1 契約作成成功時に進行状態・履歴・スコアを更新する
  - 更新結果を即時に UI へ反映する
  - _Requirements: 1.3, 3.1, 3.4, 4.1, 4.2, 4.4_

- [x] 7.2 契約失敗時に失敗理由と次の行動ヒントを記録・反映する
  - 直近履歴にも反映する
  - _Requirements: 3.3, 3.5_

- [x] 8. テスト整備
- [x] 8.1 状態取得・更新・履歴記録・スコア算出の動作テストを追加する
  - 進行状態と履歴の整合性を検証する
  - _Requirements: 1.3, 1.5, 2.2, 3.5, 4.1, 5.4_

- [x] 8.2 ログインゲート、ダッシュボード、契約フローの表示テストを追加する
  - 空状態と導線の表示を検証する
  - _Requirements: 1.1, 1.2, 1.4, 2.1, 3.1, 5.1, 5.3, 5.5_

- [x] 8.3 目標・結果・スコア・履歴パネルの表示テストを追加する
  - 失敗理由や差分表示の検証を含める
  - _Requirements: 2.3, 2.4, 2.5, 3.2, 3.4, 4.2, 4.3, 4.5_
